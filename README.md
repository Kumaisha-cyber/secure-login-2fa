# 🔐 Secure Login System with 2FA

A secure authentication system built with Python Flask that protects user accounts using password hashing and Two-Factor Authentication (2FA).

## 🚀 Live Demo

🔗 https://secure-login-2fa-5o8v.onrender.com

## ✨ Features

* 📝 User Registration
* 🔐 Secure Password Hashing using Bcrypt
* 🗄️ SQLite Database
* 🔑 Username and Password Authentication
* 📱 Two-Factor Authentication (2FA)
* 🔢 Time-Based One-Time Password (TOTP)
* 📷 QR Code Setup for Authenticator Apps
* 🛡️ Protected Dashboard
* 🚪 Secure Logout
* 🌐 Deployed on Render

## 🛠️ Technologies Used

* Python
* Flask
* Flask-SQLAlchemy
* Flask-Bcrypt
* PyOTP
* QRCode
* Pillow
* SQLite
* Gunicorn
* Render

## 🔒 How the Authentication Works

```text
User Registration
        ↓
Password is Hashed
        ↓
User Data Stored in Database
        ↓
Username + Password Login
        ↓
2FA OTP Verification
        ↓
Secure Dashboard Access
```

## 🔐 Security Features

### Password Hashing

Passwords are not stored as plain text. They are securely hashed using Flask-Bcrypt before being stored in the database.

### Two-Factor Authentication

After entering the correct username and password, the user must enter a time-based 6-digit OTP generated by an authenticator app.

### Protected Dashboard

The dashboard can only be accessed after successful authentication and 2FA verification.

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Kumaisha-cyber/secure-login-2fa.git
```

### 2. Open the Project

```bash
cd secure-login-2fa
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

```text
http://127.0.0.1:5000
```
